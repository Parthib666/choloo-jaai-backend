# Choloo Jaai Backend

Backend API service for the Choloo Jaai event management platform.

## Technology Stack

- NestJS
- TypeScript
- PostgreSQL
- Prisma ORM
- Redis

## Responsibilities

The backend handles:

- User management
- Authentication
- Event management
- Ticket booking
- Corporate event requests
- Payments
- Notifications
